Lecture Notes to Study Pack

A human-in-the-loop prompt workflow that turns permitted lecture notes into structured revision material and checks the outputs against the source.

How this prototype worksThis is a prompt-only workflow helper. It prepares P1, P2 and P3 prompts, then you run each prompt in ChatGPT or Google AI Studio and paste the real output back here. It does not make an automatic model/API call, and your notes remain in this browser session until you export or close it.
